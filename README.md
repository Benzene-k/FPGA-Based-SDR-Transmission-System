# FPGA-Based-SDR-Transmission-System
This project is based on two sets of FPGAs and a host computer to build an SDR wireless communication system, enabling short-range wireless information transmission.
The transmitting end completes data processing, encoding, and digital modulation through the FPGA, and sends the signals via the radio frequency link and antenna; the receiving end uses the FPGA to perform signal acquisition, digital demodulation, and data recovery, which are ultimately uploaded to the host computer for display. The system adopts a modular design, allowing flexible adjustment of modulation methods, carriers, and communication parameters, and provides an experimental platform for further research on channel coding and intelligent demodulation algorithms.
本作品基于两组FPGA与上位机构建SDR无线通信系统，实现短距离信息的无线传输。
发送端通过FPGA完成数据处理、编码与数字调制，并经射频链路和天线发送；接收端利用FPGA完成信号采集、数字解调与数据恢复，最终上传至上位机显示。系统采用模块化设计，可灵活调整调制方式、载波及通信参数，并为信道编码和智能解调算法的进一步研究提供实验平台。
